# Release Data Model

This feature does not alter application persistence. Its transient release model is:

## Release Request

- `source`: manual dispatch, reusable workflow call, or eligible release tag
- `marketing_version`: normalized numeric iOS version
- `notes`: optional operator/release notes
- `bundle_identifier`: repository variable or `am.sure.mobile`
- `build_number`: unique UTC-based numeric value generated by the build job

## Signing Configuration

- Apple team identifier
- distribution certificate name, encoded certificate, and password
- provisioning profile name and encoded profile
- temporary keychain password

## Upload Configuration

- App Store Connect API key identifier
- API issuer identifier
- encoded API private key

## Release Result

- preflight outcome
- signed IPA path/artifact
- upload command outcome
- cleanup outcome
- downstream App Store processing state (external and asynchronous)
